# Loading Screen

**Name:** Torres, Sean Gabrielle
**Section:** IT3R4

## Description
A recreation of Slack's iconic loading screen built with HTML, CSS, and a
touch of JavaScript. It displays the classic Slack loading message with a
spinning loader centered on the page, plus rotating "Did you know?" coding
facts that fade in and out every few seconds.

## How to Run
1. Clone this repository.
2. Open `loadingScreen.html` in any modern web browser.
   - You can open it by clicking the right mouse button and tap "Open with Live Server" (make sure you have the extension "Live Server" downloaded on your IDE) so you don't need to manually enter the whole thing in the search bar. ^^

No installation, dependencies, or build tools required — it's pure
HTML, CSS, and vanilla JavaScript.

## Files
- `loadingScreen.html` — page markup and structure
- `styles.css` — styling and spinner/fade animations
- `facts.js` — rotates the coding facts on a timer
